---
description: Frontend UI/UX Guidelines
---
1. **Framework:** Modern React using Vite.
2. **Design Philosophy:** 
   - Ensure the app visually "WOWs" the user. 
   - Utilize standard Tailwind CSS features for glassmorphism (`backdrop-blur-*`, semi-transparent backgrounds).
   - Do NOT use generic red, blue, green; use cohesive palettes (e.g., violet/fuchsia dark mode).
   - Use dynamic features: framer-motion micro-animations on cards, buttons, and state changes.
3. **Typography:** Use modern web fonts like `Inter` or `Outfit`.
4. **Components:**
   - Keep components small and reusable.
   - Utilize a unified Design System (buttons, input fields, cards).
5. **Data Visualization:** Use `mermaid.js` embedded in a React component to dynamically display architectural diagrams generated by the AI.
